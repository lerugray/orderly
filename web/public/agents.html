    What a named agent has, and what it does not

    It holds no credential, and this page cannot give it one. Mail, the calendar and web research stay with the identities that already own them. A named agent cannot ask them to work on its behalf: delegation is off and there is no switch here that turns it on.

    It does not have a sealed container of its own yet. Its conversation and its transcript are genuinely separate, and it is told plainly that it may not delegate — but that last part is an instruction, not a wall, because the seat answering it is still the coordinator's. Until each identity gets its own sandbox and passes the container checks, treat a named agent as a separate conversation, not a separate confinement. The checks that have run are listed against each one below; the ones still owed are listed beside them.
