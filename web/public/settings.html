Desk theme

A theme changes only the palette and mascot — never the layout or what this desk can do. The choice is kept in this browser and applies immediately to every desk page. Night Desk is the original look.

The station's models

Every agent uses these unless it is given its own below. Fallbacks are tried, in order, when the main model won't answer.

Per agent

How should replies to you read?

This changes how the station talks to you. It does not add capabilities or change approvals. Task accuracy and genuinely required clarification still win.
